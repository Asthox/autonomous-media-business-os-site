Data Deletion

How to disconnect accounts and remove AMBOS application data.

Steps1. Disconnect2. Local data3. Request

1. Disconnect a Connected Account

Use the account or integrations area in AMBOS to disconnect a supported account when that control is available. You can also revoke AMBOS from the connected platform's own account settings. Revoking access prevents AMBOS from using the associated authorization credentials in future requests.

2. Remove Local AMBOS Data

Because AMBOS is designed as a desktop application, working data and configuration may be stored locally. You can remove content from the Application and, where appropriate, uninstall AMBOS or remove its application-data directory to delete locally stored information.

Deleting local AMBOS data does not automatically delete content that you have already published to an external platform. Manage published content directly through that platform.

3. Privacy or Deletion Request

If you believe AMBOS's operator holds information about you that cannot be removed through the controls above, send a request to YOUR_EMAIL@example.com with the subject AMBOS Data Request. Please do not send passwords, access tokens or other account secrets by email.
